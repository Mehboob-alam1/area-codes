# Data sources

| Source | Use |
|---|---|
| mledoze/countries | Country names, ISO codes, capitals, continents, currencies, languages and calling-code fields |
| flagcdn | Flag images addressed by ISO alpha-2 code |
| ITU-T E.164 | International numbering standard. Not a city-code feed |
| ITU national numbering plans | Index of official plans. Not bulk-imported |
| NANPA | Curated United States, Canada and other NANP codes |
| Ofcom | Curated United Kingdom geographic codes |
| Curated national references | Other geographic codes, stored as unverified until review |
| libphonenumber-js | Parse, format and pattern checks |

REST Countries v3 is deprecated. This project does not call it at request time. Twilio Lookup is not enabled.

A missing code is left blank. Mobile prefixes are not stored as city area codes.
